## Version 3.0.1 (2026-05-16)
### Added
- Add local dependency bundling for JavaScript files that use `require` (CommonJS) or `import` (ES Module).
- Add support for `.cjs` files alongside `.js` and `.mjs`.
- Add bundle metadata to generated `.syamkey` files, including bundled file list and detected module type.
- Add automated CLI roundtrip tests for single-file, CommonJS bundle, and ES Module bundle workflows.

### Changed
- Run dependency collection and bundling before applying the existing SyamCode minify, hash obfuscation, and `.syamkey` generation flow.
- Preserve external package and Node built-in imports as runtime dependencies while bundling local relative imports such as `./helper.js` and `../lib/index.js`.

### Fixed
- Fix restore compatibility with the current Syamkey v3 format generated by the minify command.
